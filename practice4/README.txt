Practice 04 - Python Advanced Topics

Files:
- generators.py : iterators, iter(), next(), custom iterator, yield, generator expression
- dates.py      : datetime, date formatting, differences, timedelta, timezone
- math.py       : built-in math functions, math module, random module
- json.py       : JSON parsing, creation, reading/writing JSON files
- sample-data.json : sample JSON data for testing json.py

Run:
    python generators.py
    python dates.py
    python math.py
    python json.py

The json.py program also creates student.json automatically.
